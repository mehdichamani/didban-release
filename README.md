# 🛡️ دیدبان (Didban) - بسته نصبی و خروجی‌های رسمی

سامانه هوشمند و یکپارچه پایش، نظارت و گزارش‌گیری تجهیزات نظارت تصویری Hikvision.  
این مخزن میزبان بسته‌های اجرایی مستقل کامپایل‌شده (Standalone)، اسکریپت‌های نصب هوشمند و انتشارهای رسمی نرم‌افزار دیدبان است.

---

## ⚡ ۱. نصب سریع و هوشمند با یک دستور (توصیه‌شده)

برای نصب خودکار بسته مستقل (بدون نیاز به نصب پایتون، کامپایلر یا هیچ پیش‌نیازی)، کافی است دستور زیر را در ترمینال سیستم‌عامل خود اجرا نمایید:

### 🐧 در لینوکس (Ubuntu, Debian, RHEL, CentOS, Arch):
ترمینال را باز کرده و دستور زیر را اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/mehdichamani/didban-release/main/install.sh | bash
```

> **ویژگی‌های اسکریپت نصب لینوکس:**
> - دانلود خودکار آخرین نسخه پایدار از مخزن ریلیز
> - استخراج در مسیر دلخواه (پیش‌فرض: `/opt/didban` یا `~/didban`)
> - ساخت پوشه `data/`
> - دریافت تعاملی نام کاربری و رمز عبور مدیر و تولید هش امن رمز توسط موتور برنامه
> - پیکربندی خودکار فایل `.env`
> - راه‌اندازی و فعال‌سازی سرویس پس‌زمینه خودکار لینوکس (`systemd`)
> - قابلیت تشخیص نصب قبلی و به‌روزرسانی (Update) سریع بدون آسیب به تنظیمات و داده‌ها

---

### 🪟 در ویندوز (Windows 10, 11, Windows Server):
پنجره **PowerShell** را باز کرده و دستور زیر را اجرا فرمایید:

```powershell
irm https://raw.githubusercontent.com/mehdichamani/didban-release/main/install.ps1 | iex
```

> **ویژگی‌های اسکریپت نصب ویندوز:**
> - دانلود و استخراج خودکار آخرین پکیج ۶۴ بیتی ویندوز
> - استخراج در مسیر دلخواه (پیش‌فرض: `C:\Didban`)
> - دریافت امن رمز عبور و هش آن با `main.exe`
> - ایجاد فایل‌های مدیریتی `didban.bat` و `didban.ps1`
> - فعال‌سازی اجرای خودکار در پس‌زمینه ویندوز هنگام روشن شدن سیستم (Windows Startup)
> - اجرای فوری سرویس و باز کردن پنل تحت وب در مرورگر
> - پشتیبانی از به‌روزرسانی مستقیم به نسخه‌های جدید با حفظ کامل پایگاه‌داده

---

## 🔄 ۲. نحوه به‌روزرسانی سامانه به نسخه جدید (Update)

هر زمان نسخه جدیدی از دیدبان منتشر شود، بدون نگرانی از دست رفتن اطلاعات یا تنظیمات، کافی است:

- **در لینوکس:** دستور نصب را مجدداً اجرا فرمایید تا گزینه Update فعال شده و نسخه جدید جایگزین گردد:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/mehdichamani/didban-release/main/install.sh | bash
  ```
- **در ویندوز:** دستور زیر را در پوشه برنامه اجرا نمایید یا دستور نصب را مجدداً بزنید:
  ```powershell
  .\didban.bat update
  ```

---

## 📦 ۳. نصب دستی (محیط‌های آفلاین و ایزوله)

در صورتی که سرور شما به اینترنت دسترسی مستقیم ندارد:
1. بسته متناسب با سیستم‌عامل خود را از بخش **[Releases](https://github.com/mehdichamani/didban-release/releases)** روی یک رایانه دیگر دانلود نمایید:
   - لینوکس: `didban-linux-x86_64.tar.gz`
   - ویندوز: `didban-windows-x86_64.zip`
2. بسته را به سرور منتقل کرده و اکسترکت فرمایید.
3. فایل نمونه `.env.example` را به `.env` تغییر نام داده و مشخصات را تنظیم کنید.
4. پوشه‌ای به نام `data` در کنار فایل اجرایی بسازید و برنامه را اجرا نمایید.

---

## 🛠️ دستورات مدیریت سرویس پس از نصب

### در لینوکس:
```bash
sudo systemctl status didban    # مشاهده وضعیت سرویس
sudo systemctl restart didban   # راه‌اندازی مجدد
sudo systemctl stop didban      # توقف موقت سرویس
journalctl -u didban -f         # مشاهده لاگ‌های زنده
```

### در ویندوز:
در پوشه نصب برنامه (مثلاً `C:\Didban`):
```cmd
didban.bat status          # بررسی وضعیت اجرای سرویس
didban.bat stop            # متوقف‌سازی سرویس
didban.bat start-bg        # اجرای سرویس در پس‌زمینه
didban.bat restart         # راه‌اندازی مجدد سرویس
didban.bat enable-startup  # فعال‌سازی اجرای خودکار در استارت‌آپ ویندوز
```
