# 🛡️ دیدبان (Didban) - بسته نصبی و خروجی‌های رسمی

این مخزن برای نگهداری و انتشار خودکار خروجی‌های باینری و بسته‌های اجرایی نرم‌افزار **دیدبان (سامانه هوشمند پایش تجهیزات نظارت تصویری Hikvision)** ایجاد شده است.

---

## 📥 دانلود آخرین نسخه
برای دانلود بسته‌های آماده اجرا برای سیستم‌عامل‌های مختلف به بخش **[Releases](https://github.com/mehdichamani/didban-release/releases)** مراجعه کنید.

### محتویات پکیج:
- فایل اجرایی مستقل کامپایل‌شده (Standalone Binary بدون نیاز به نصب پایتون)
- فایل نمونه تنظیمات محیطی (`.env.example`)
- راهنمای جامع استقرار و راه‌اندازی

---
*کلیه نسخه‌ها به صورت خودکار از طریق GitHub Actions بیلد و امضا می‌شوند.*
